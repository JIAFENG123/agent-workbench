# 亚马逊美国站商品文案与上架合规规则（示例文档）

> 本文档仅用于本地演示 Agent Workbench 的检索链路，内容为简化整理的示例规则，
> 不构成任何法律或平台政策建议。实际运营请以 Amazon Seller Central 官方最新政策为准。

## 1. 商品标题（Title）规则

1. 标题长度不超过 200 个字符，建议控制在 80–150 字符之间。
2. 标题必须使用完整、连贯的自然语言，禁止全部大写、禁止关键词堆砌（如连续罗列同义词）。
3. 标题禁止出现以下内容：
   - 促销与主观评价词：`best seller`、`best-selling`、`hot sale`、`top rated`、`No.1`、`#1`、`amazing`、`perfect` 等。
   - 价格、折扣、运费信息：`free shipping`、`50% off`、`cheap` 等。
   - 卖家信息：店铺名、邮箱、网址、电话号码。
   - 特殊符号：`~ ! * $ ? _ ~ { }` 等，仅允许连字符与斜杠在必要场景使用。
4. 儿童玩具类目标题必须包含：品牌名 + 产品名称 + 适用年龄（如 `Ages 3+`）+ 型号（如有）。

## 2. 五点描述（Bullet Points）规则

1. 每条不超过 500 个字符，总计 5 条。
2. 不得使用 HTML 标签、表情符号或全大写短语。
3. 不得对产品功效做绝对化承诺（如 `cures`、`guaranteed 100% safe`）。
4. 涉及电池、磁性部件、小零件等，必须在描述中提示安全警告。

## 3. 儿童玩具类目（Toys & Games）特殊要求

1. 所有面向 12 岁及以下儿童的玩具，必须提供 CPC 证书（Children's Product Certificate），
   依据 CPSIA 由 CPSC 认可的第三方实验室出具。
2. 页面需标注制造商建议适用年龄，并与 CPC 证书中的年龄分级一致。
3. 含小零件且适合 3 岁以下儿童的玩具，须有窒息危险警告标识。
4. 含铅、邻苯二甲酸酯超标的玩具禁止上架；涂层材料须符合 CPSIA 铅含量 ≤ 100 ppm。
5. 电动玩具需提供电池类型与安全说明；纽扣电池类产品须符合 Reese's Law 相关要求。

## 4. 图片与 A+ 内容

1. 主图必须为纯白背景（RGB 255,255,255），产品占画面 85% 以上。
2. 主图禁止出现：文字、水印、Logo 角标、促销信息、道具或非售卖配件。
3. 场景图与信息图可含文字，但不得出现 `best seller`、`top rated` 等评价性用语。

## 5. 常见违规处罚

| 违规类型 | 首次 | 重复违规 |
|---|---|---|
| 标题含促销词 | 系统警告并要求 24 小时内修改 | Listing 被下架 |
| 缺少 CPC 证书（儿童玩具） | Listing 冻结 | 账号受限 |
| 图片不合规 | 图片被隐藏 | Listing 被下架 |
| 功效绝对化承诺 | 系统警告 | 账号审核 |

## 6. 高频问答

Q: 标题里能不能出现 "best seller"？
A: 不能。`best seller` 属于促销与主观评价词，标题、五点描述和图片文字中均禁止出现，
   系统会发出警告并要求修改，重复违规会导致 Listing 下架。

Q: 儿童玩具没有 CPC 证书可以先上架吗？
A: 不可以。儿童玩具上架前必须完成 CPC 认证并在被抽查时提供，否则 Listing 会被冻结。

Q: 标题全部大写会怎样？
A: 属于格式违规，系统通常要求 24 小时内修改，长期不改会被下架。
